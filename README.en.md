This is a Python code that can be used to create many pop-up windows in a window to show care and greetings to friends. The names can be changed directly.

## Features

- Creates 150 pop-up windows with random tips and greetings.
- Each window displays a random tip from a predefined list.
- Windows are randomly positioned on the screen with minimal overlap.
- Press the spacebar to exit all windows.

## Quick Start

### Prerequisites

- Python 3.x
- tkinter library (usually included with Python)

### Running the script

1. Clone the repository or download the `main.py` file.
2. Open a terminal or command prompt.
3. Navigate to the directory containing `main.py`.
4. Run the script:

   ```bash
   python main.py
   ```

5. The pop-up windows will appear one by one. Press the spacebar to exit.

## Customization

You can customize the tips and background colors by editing the `tips` and `bg_colors` lists in the `main.py` file. You can also change the `person_name` variable to personalize the greetings.
